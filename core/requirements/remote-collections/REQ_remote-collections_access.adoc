[[req_remote-collections_access]]
[requirement]
====
[%metadata]
identifier:: /req/remote-collections/access

[.component,class=description]
--
For referencing a <<def_remote-collections,remote collection>> as a source of <<sc_process_inputs,input values to a process>>:
--

[.component,class=part]
--
The server SHALL support accessing <<def_remote-collections,remote collections>> using at least one supported <<def_data-access-mechanism,OGC API data access mechanism>>.
--

[.component,class=part]
--
The server SHALL, in the <<ogc_process_description,process description>> and for each relevant input, indicate which <<def_data-access-mechanism, OGC data access API(s)>> can be used to retrieved input values for that input from the <<def_local-collection,collection>>.
--
