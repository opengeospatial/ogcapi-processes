[[req_collection-output_response-output-many-results]]
[requirement]
====
[%metadata]
identifier:: /req/collection-output/response-output-many-results

[.component,class=conditions]
--
. The <<sc_execute_process,Execution request>> includes the `response` parameter by <<req_collection-output_response-definition,query or property>> as appropriate for the HTTP request strategy.
. The value of the `response` parameter is `collection`.
. The number of requested outputs (whether <<implicit-explicit-outputs,implicitly or explicitly>>) is more than one.
. The <<con-neg-by-profile,negotiated profile>> is `https://www.opengis.net/def/profile/OGC/0/ogc-results`.
--

[.component,class=part]
--
The server SHALL respond with an HTTP status code of https://datatracker.ietf.org/doc/html/rfc7231#section-6.3.1[200].
--

[.component,class=part]
--
The media type of the response SHALL be `application/json`.
--

[.component,class=part]
--
The content of response SHALL conform to the <<schema_results,results.yaml>> schema.
--

[.component,class=part]
--
Each collection output in the response SHALL be a link to a <<def_collection-description,collection description document>>.
--

[.component,class=part]
--
The <<profile-uris,profile URI>> SHALL be returned in the response
with HTTP header `Link: href="https://www.opengis.net/def/profile/OGC/0/ogc-results", rel="profile"`.
--

====
