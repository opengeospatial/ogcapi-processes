[[req_ogc-process-description_data-classes]]
[requirement,label="/req/ogc-process-description/data-classes"]
====
[%metadata]
identifier:: /req/ogc-process-description/data-classes

[.component,class=part]
--
The `dataClasses` parameter SHALL be an array of zero or more items.
--

[.component,class=part]
--
Each item in the `dataClasses` array SHALL be one of the following:

. The identifier of a data class in the OGC Data Classes Register (the `dataClassId` value in the URI template https://www.opengis.net/def/dataClass/OGC/0/{dataClassId});

. A Safe CURIE representing the data class such as `[ogc-dataClass:{dataClassId}]` or `[ogc-bblocks:{some-data-class}]`.

. A HTTP(S) URI of a data class in another normative register.

. Another form of register reference with a valid URI schema (e.g., `bblocks://ogc.some.data.class`).
--
