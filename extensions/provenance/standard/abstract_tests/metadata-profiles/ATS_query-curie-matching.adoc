[[ats_metadata-profiles_query-curie-matching]]

[abstract_test]
====
[%metadata]
identifier:: /conf/metadata-profiles/query-curie-matching
target:: /req/metadata-profiles/query-curie-matching
test-purpose:: Validate that Safe CURIEs and their expanded URIs are matched as aliases.
test-method::
+
--
1. Issue a filter using a Safe CURIE `<role>`/`<profile>` (query parameter and `QUERY` method), and a filter using the equivalent expanded URIs.

2. Validate that both return the same processes, whether the process description metadata use the Safe CURIE or the URI.

3. Issue the query parameter form `+++metadata[<scope>][[<curie>]]=[<curie>]+++`, and validate that it returns
the same processes as the equivalent expanded URIs (or an error, if literal brackets are refused as per
<<per_metadata-profiles_query-literal-brackets,/per/metadata-profiles/query-literal-brackets>>).
--
====
