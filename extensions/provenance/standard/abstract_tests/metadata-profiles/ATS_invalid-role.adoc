[[ats_metadata-profiles_invalid-role]]

[abstract_test]
====
[%metadata]
identifier:: /conf/metadata-profiles/invalid-role
target:: /req/metadata-profiles/invalid-role
test-purpose:: Validate that a valid but uninterpretable `<role>` or `<profile>` is reported as unprocessable.
test-method::
+
--
1. Issue a `GET` request on `{root}/processes` with a `metadata[process][<role>]=<profile>` filter where the `<role>`
or `<profile>` is a valid IRI, URN or Safe CURIE that the server cannot interpret (e.g., a Safe CURIE with an unknown
prefix).

2. Validate that the response status code is 422 and that the media type is `application/problem+json` (<<rfc9457,RFC 9457>>).

3. Validate that the `type` is `pass:[https://www.opengis.net/def/exceptions/ogcapi-processes-5/1.0/unsupported-metadata-profile]`
and that the `instance` is the offending `<role>` or `<profile>` value.

4. If the `QUERY` method is supported, repeat the steps with the filter provided in the request content.
--
====
