[[ats_metadata-profiles_query-parameter]]

[abstract_test]
====
[%metadata]
identifier:: /conf/metadata-profiles/query-parameter
target:: /req/metadata-profiles/query-parameter
test-purpose:: Validate that `GET /processes` supports the `metadata[process|inputs|outputs][<role>]=<profile>` parameters.
test-method::
+
--
1. Select a process with profile metadata at the process level, and issue a `GET` request on `{root}/processes?metadata[process][<role>]=<profile>` (percent-encoded).

2. Validate that the response status code is 200 (OK) and that the process is listed.

3. Repeat with `metadata[inputs][<role>]=<profile>` and `metadata[outputs][<role>]=<profile>` for an input and an output profile.

4. Repeat with multiple profiles for the same role, as comma-separated values and as repeated parameters, and validate that both return the same result.
--
====
