[[req_metadata-profiles_invalid-metadata-profile]]
[requirement]
====
[%metadata]
identifier:: /req/metadata-profiles/invalid-metadata-profile

[.component,class=conditions]
--
. A `<role>` or `<profile>` of the filters is not a valid IRI (<<rfc3987,RFC 3987>>), URN (<<rfc8141,RFC 8141>>)
or Safe CURIE, as required by <<req_metadata-profiles_profile-link,/req/metadata-profiles/profile-link>>.
--

[.component,class=part]
--
The server SHALL respond with the HTTP status code `400` (Bad Request).
--

[.component,class=part]
--
The response SHALL use the media type `application/problem+json` (<<rfc9457,RFC 9457>>).
--

[.component,class=part]
--
The `instance` of the response content SHALL be the offending `<role>` or `<profile>` value of the filters,
percent-encoded as needed to form a URI reference (<<rfc3986,RFC 3986>>).
--

[.component,class=part]
--
The `type` of the response content SHALL be `pass:["https://www.opengis.net/def/exceptions/ogcapi-processes-5/1.0/invalid-metadata-profile"]`.
--

====
