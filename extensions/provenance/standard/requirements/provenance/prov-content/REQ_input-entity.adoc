[[req_provenance_prov-content_input-entity]]
[requirement]
====
[%metadata]
identifier:: /req/provenance/prov-content-input-entity

[.component,class=part]
--
For each job input submitted for process execution,
the PROV metadata SHALL provide a link:https://www.w3.org/TR/prov-o/#Entity[`prov:Entity`] definition
that employs the `prov:type` property with (at least) the value `wfprov:Artifact`.
--

[.component,class=part]
--
For each job input submitted for process execution,
the PROV metadata SHALL include a `prov:used` association between
to the corresponding data input entity and the <<req_provenance_prov-content_job-activity,PROV Job Activity>>.
--

[.component,class=part]
--
For each `prov:used` association, a `prov:role` property SHALL be provided
with a value that allows identification of the `{inputID}` for the corresponding process input.
--

====
