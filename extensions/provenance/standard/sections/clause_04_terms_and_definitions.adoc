== Terms, definitions and abbreviated terms

[[sc_terms-and-definitions]]
=== Terms and definitions

See <<OAProc-1>>, Clause 4.1.

The following additional terms and definitions apply to this document.

[[def_knowledge-graph]]
==== knowledge graph

graph-structured representation of concepts, resources and the typed relationships between them, typically expressed
using RDF statements (subject, predicate, object) such that it can be queried and traversed

[[def_metadata-role-parameter]]
==== metadata role parameter

`<role>` placeholder of a filter defined by the _Metadata Profiles_ requirements class, in the form of
a query parameter `metadata[<scope>][<role>]=<profile>` or of a member of the `QUERY` content.
It is an IRI, URN or Safe CURIE that identifies the concept to match against the `role` of
the profile link entries in the `metadata` list field of a process, input or output

[[def_metadata-profile-parameter]]
==== metadata profile parameter

`<profile>` placeholder of a filter defined by the _Metadata Profiles_ requirements class, associated with
a <<def_metadata-role-parameter,metadata role parameter>>.
It is an IRI, URN or Safe CURIE that identifies the profile to match against the `href` of
the profile link entries having that `role`
