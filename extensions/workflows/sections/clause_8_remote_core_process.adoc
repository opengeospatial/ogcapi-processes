=== Requirement Class _Remote Core Processes_

The _Remote Core Processes_ conformance class allows to reference and execute an OGC API <<def_remote-process>>
using the _Core_ conformance class of <<OAProc-1>> in addition to any local process.

and how an implementation executes that remote process to use as an input to another process.
